# Sphere3D

[English](README.md) · **Русский**

**Многопользовательская 3D-арена в браузере в реальном времени: катите сферу, ешьте шарики, становитесь больше всех.**
Идея как у agar.io, но с настоящей физикой твёрдых тел, 3D-камерой и авторитетным сервером.

> **Pet-проект для портфолио, разработан AI-first подходом.** Почти весь код написал ИИ-агент под моим руководством.
> Живая версия на sphere3d.ru выключена (я перестал платить за хостинг), поэтому запускайте локально, это одна команда с Docker.
> Честный разбор сильных и слабых сторон проекта: [docs/AUDIT.md](docs/AUDIT.md) (на английском).

## Возможности

- **Физика в основе геймплея.** Сферы катятся в симуляции Rapier 3D, которая работает на сервере с частотой 30 Гц.
- **Авторитетный сервер и клиентское предсказание.** Ввод проверяется и ограничивается по частоте на сервере, скорость зажимается, клиент предсказывает движение локально и сверяется с патчами сервера.
- **Механики в духе agar.** Ешьте шарики и меньших игроков, делитесь на до 4 частей (`E`), выбрасывайте массу, ускоряйтесь за счёт массы (`Shift`), тормозите (`Пробел`).
- **Ежи-ловушки**, наказывающие за неосторожное движение.
- **Боты**, чтобы арена не пустовала (до 50 игроков в комнате, матч 15 минут).
- **Публичная арена и приватные лобби** по короткому коду.
- **Аккаунты.** Игра гостем или email + пароль с подтверждением почты (SMTP), JWT access и refresh токены.
- **Метагейм.** 15 скинов (эмодзи, узорчатые, светящиеся), магазин за монеты, топ (за день и за всё время), друзья, чат с фильтром, киллфид и экран смерти.
- **Мобильная версия.** Виртуальный джойстик и экранные кнопки, PWA-манифест.

## Стек

| Слой | Технологии |
|---|---|
| Клиент | TypeScript, Vite, Babylon.js 7, colyseus.js |
| Realtime-сервер | Node 22, Colyseus 0.15 (`@colyseus/schema`), Rapier 3D |
| API | Express, JWT, bcrypt, nodemailer |
| Данные | PostgreSQL 16 (аккаунты, статистика), Redis 7 (топ, опционально) |
| Общий код | npm workspace `shared/`: константы, кинематический шаг, типы сообщений и API, каталог скинов |
| Инфраструктура | Docker Compose, nginx, Let's Encrypt, деплой-скрипты на Python (paramiko) |

Около 14 тысяч строк TypeScript, CSS и SQL.

```
client/   Рендер на Babylon.js, ввод, HUD, меню, сетевой код (предсказание, интерполяция)
server/   Комнаты Colyseus, мир Rapier, боты, античит, REST API, сервисы
shared/   Код для обеих сторон, чтобы предсказание клиента совпадало с сервером
docs/     Заметки об архитектуре, аудит, медиа
deploy/   Продакшен-compose, конфиг nginx, настройка сервера
```

Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Дорожная карта: [ROADMAP.md](ROADMAP.md).

## Локальный запуск

### Docker (всё сразу: Postgres, Redis, сервер, клиент)

```bash
docker compose up --build -d
```

Откройте http://localhost:8080.

### Без Docker (гостевой режим, без базы данных)

Аккаунты, магазин и постоянная статистика требуют Postgres. Гостевая игра работает без него.

```bash
npm install
npm run build -w @spherio/shared
npm run dev:server      # http://localhost:2567
npm run dev:client      # http://localhost:5173 (проксирует /api и /colyseus)
```

### Настройка

Скопируйте `.env.example` в `.env`. Для всего, что доступно из интернета, задайте надёжный `JWT_SECRET`: в production сервер не запустится с дефолтным. Для подтверждения почты нужны переменные `SMTP_*`.

## Управление

| Ввод | Действие |
|---|---|
| `WASD` / стрелки | Движение (относительно экрана) |
| `Пробел` | Торможение |
| `E` | Разделение |
| `Shift` | Ускорение (тратит массу) |
| `Enter` | Чат |
| Касание | Джойстик и кнопки |

## Известные ограничения

Это pet-проект, а не продукт. Прочитайте [docs/AUDIT.md](docs/AUDIT.md), прежде чем что-то переиспользовать: автотестов нет, гостевые сессии живут в памяти сервера, а часть зависимостей имеет известные уязвимости.
